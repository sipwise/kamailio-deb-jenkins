Project discontinued
====================

This repository provided the setup for building Debian packages for the [Kamailio project](http://www.kamailio.org/).

kamailio-deb-jenkins was deprecated by the end of 2025 and migrated to projects maintained within the Kamailio project itself.
Take a look at [kamailio-infra](https://github.com/kamailio/kamailio-infra) + [jenkins-jobs](https://github.com/kamailio/jenkins-jobs) instead.
